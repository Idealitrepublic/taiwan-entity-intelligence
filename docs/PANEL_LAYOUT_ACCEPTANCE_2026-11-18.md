# 左右資訊欄排版驗收

本輪先在本機修改並發布 Preview，待使用者確認後再同步正式版。

## 修改

- 左欄關係路徑的中英文標題、來源識別碼、日期及長網址可在欄寬內換行。
- 資料欄位採可縮小的雙欄，手機改為上下排列。來源標題與標記可換行。
- 判決與裁罰頁籤各只顯示一個官方查詢連結。
- 關係摘要和公司選擇器在這兩個頁籤隱藏，返回總覽後恢復。
- 公司、人物、機關與路徑資料背景載入使用相同的官方查詢內容，
  防止非同步回應重新寫入紀錄、空狀態或篩選器。

## 驗證

| 項目 | 結果 |
|---|---|
| 1440、1280、1024、768、390 像素 | 長來源文字無水平超出資訊卡或側欄，頁面無水平捲動 |
| 判決與裁罰 | 頁籤各只有指定官方連結，無摘要、公司選擇器、紀錄或篩選器 |
| 非同步載入 | 切換頁籤後公司背景載入不覆寫連結 |
| 公司與機關 | 來源與長地址完整顯示，查詢連結一致 |
| Workspace 手機登入視窗 | 版面未超出視窗。登入後私有流程未在本輪重測 |
| 修改前回放 | 相同測試重現摘要錯誤顯示於查詢頁籤 |
| 原有圖譜 | 公司中介、Evidence、標案、董監事展開與四種桌面尺寸通過瀏覽器測試 |
| 自動驗證 | 538 項 Python 測試、250 項 PostgreSQL 檢查、UI 函式測試、lint 和 build 通過 |

瀏覽器回歸使用測試資料，Preview 另以既有真實中介範例查驗。
本輪無資料庫寫入、migration 或正式站發布。
