# 首版公開關係圖驗收

公開範圍為公司登記、董監事等來源內職務、政治人物公開任期、團體名冊及已覆核的官方決標。司法和勞動裁罰各提供官方查詢。政治獻金、裁罰、裁判、財產申報及候選人不進首版圖譜。既有原件、關係和收藏可供後續授權覆核。

團體名冊中歷史觀測依原始資料日期顯示。沒有可驗證端點時，搜尋仍可找到名冊實體，圖譜可能沒有鄰接關係。公司最短路徑沿用既有一至三段查詢，現況只回傳首版資料所支持的路徑。Development 的 age 備份已完成本機隔離還原，30 個資料表、33 筆 migration、匿名可讀筆數與權限一致。

## 正式發布步驟

1. 擷取當前正式版本、備份清單、migration ledger、匿名與登入權限基準。從原正式資料庫建立 age 加密備份，驗證可解密，再用隔離環境演練還原。
2. 確認待套用 migration 的檔名、順序和目標環境。先在隔離還原的正式庫演練，核對既有 Workspace、收藏和權限，驗證匿名請求看不到候選與原始列。
3. 分階段驗收限流。Vercel 上現有規則只記錄超限。啟用阻擋前先驗證搜尋、關係擴張與 PDF 在正常流量下可用，並測試受限的 HTTP 429／Retry-After。
4. 正式發布後抽查同一組公司／人物／團體／標案，核對瀏覽器、API、Evidence、PDF、兩帳號權限與錯誤記錄。核心失敗時切回已確認的可回滾部署，保留資料的發布限制並重新確認舊版讀取出口。
5. 來源更正時保留舊版本和來源，先撤下受影響內容，再寫入待核的新版本。以新請求重查搜尋、圖譜及新下載的 PDF，核對舊內容已消失。已下載的外部副本須提示重新下載。
