# 指定中介數與圓形讀取提示

公司路徑選項改為精確指定中介數：直接關係＝1條線；1個中介＝A→X→B；2個中介＝A→X→Y→B。兩個中介必須是不同實體，無法以同一人重複或繞回起點補足。不將一個中介的較短路徑冒充兩個中介。

新增exact_depth API參數；未傳參數的既有API使用方式仍保留最短路徑語意。僅讀Development公開關係，不新增或修改資料。查詢每端25條關係及200條中間連線，有更多資料則標示truncated，不宣稱全量。

圓形動畫顯示查路徑／展開節點的實際讀取狀態；遠端未提供完成量，因此不顯示虛構百分比。具aria-busy、狀態文字及減少動畫偏好支援。

品質檢查：獨立測試資料驗證4個不同節點3條有Evidence連線、反向連線、已有1個中介時仍找2個、不接受循環或缺Evidence、截斷及API參數。前端函式測試讀取動畫在開始／節點載入／完成的狀態切換。

資料限制：本次以Development已發布關係進行方向無關的3段路徑SQL盤點，未找到兩端皆公司且有兩個不同中介的真實案例。功能可用性與資料覆蓋必須區分；不匯入假資料作真實驗收。既有聯上開發／敦峰汽車只有吳思瑤一個中介，應在1個中介選項顯示；2個中介查詢不可沿用該單中介結果。
