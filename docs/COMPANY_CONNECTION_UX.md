# 兩家公司關係摘要與重點路徑

範圍：本機與Development Preview。沿用既有Entity／Relationship／Evidence及受限最短路徑API，
沒有新資料源、schema、migration、API、身分合併或Production修改。

## 呈現與操作

- 圖譜旁的「兩家公司關係摘要」先用白話說明A、連接節點、B；可選擇比較公司。
  展開圖譜時，同一摘要移至圖內；回到一般或窄視窗則移回側欄，保留操作及證據狀態。
  手機可按「關係摘要」直接跳到摘要。
- 既有即時公司延伸圖只使用已核對的法人董監事／共同決標來源連接；
  點另一家公司時同步選取摘要。聚焦切換淡化其他分支，不刪節點、不重設展開、拖曳或資料。
- 已發布圖譜中同時出現另一家公司，先呈現「尚未查核」與查找按鈕；
  必須由既有1–3段最短路徑查詢確認後才呈現連接順序，不以同名或共同出現猜測路徑。
- 最短路徑以來源類型顏色及虛線外框標記中介，線上常駐關係名稱與日期。
  逐段明細使用Relationship的真實起點→終點，不能把反向查找誤寫成反向捐贈或反向任職。
- 每段可開啟原有Evidence明細與原始來源。日期沒有提供則明示，不能拿取得時間替代事件日期。
- 未找到時同時在摘要與原路徑結果顯示查詢範圍、截斷提示與「不代表不存在」。
- 摘要中的↔只表示查找順序；公司延伸圖分類連接不是正式Relationship或新增Company Entity。
  共同人物、機關、案件或得標公告不能單獨證明合作、股權控制或不法。

## 變更檔案與影響

`web/index.html`新增顯示層摘要、選擇／聚焦、來源類型強調及常駐日期標籤。
`tests/connection_summary_ui.test.cjs`驗證實際出貨函式；`package.json`納入例行測試。
後端查找演算法、查詢上限、權限與資料庫均不變。

## 限制

- 只解釋已載入來源觀察或本次API回傳路徑，不新增／發布公司關係，不宣稱全國完整。
- 真實資料驗證到2段路徑；1段及3段合法資料形狀另由回歸測試驗證，未假稱有實測3段真實案例。
- 法人董監事來源未提供職務生效日期時顯示「日期未提供」，不以下載日期填補。
- 類別線及來源觀察不能當成正式股權／合作關係；證據按鈕保留原始定位及查詢範圍。
- 本輪沒有重新執行私人帳號新增／刪除收藏或真人Pilot；Auth、RLS與Report程式未改動，
  以既有回歸及PostgreSQL權限檢查確認相容，不把未做的私人端到端實測寫為PASS。
