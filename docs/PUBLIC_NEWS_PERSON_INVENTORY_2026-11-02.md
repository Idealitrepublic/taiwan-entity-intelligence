核對規則：立委使用完整姓名＋第11屆＋選區，名單提供政黨時再核對政黨；官方身分再與當屆委員會 API 及官方任期原件交叉檢查。部會首長使用完整姓名＋機關＋職務，並以行政院正式人事新聞及當次首長名錄確認脈絡。不使用新聞導航、延伸閱讀中的姓名充當本篇事件，也不把同篇出現的兩個人直接連線。

人事新聞保留「宣布／擬任」語意；2025-08-27不是每位官員的任期生效日。例如運動部成立另有日期，不能把宣布日直接寫成就任日。2024當選新聞亦不能證明2026仍在任。
