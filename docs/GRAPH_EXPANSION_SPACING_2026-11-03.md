# 展開圖譜格距及連線避讓

問題：節點雖分層，但連線共用中央軌道，標籤以兩端平均位置排列，展開後多條標籤與軌道互相覆蓋。

修正：
- 同張圖採統一中心格距，依最長節點名稱、節點尺寸、關係標籤高度及同節點連線數動態計算；不依固定小間距硬塞。
- 每條線配置獨立進出軌道，圈邊端口分散，不再全部由同一水平線及垂直幹線重疊。
- 關係標籤放在列間專屬區域；同目標多條關係另分文字列，跨層／同層線走圖外上方通道。
- 新增節點後重新排版並清除舊手動座標，防止舊拖曳位置疊住新節點；拖曳、縮放、分頁、Evidence及原公司路徑保留。
- 選中知識圖節點改以外框呈現，避免放大圓圈遮住文字或連線。

回歸：3／12／23／60節點，多層、長中英文名稱，檢查統一縱距、節點框不重疊、關係標籤框不重疊、不壓節點、線段不穿非端點節點與標籤。
471 Python tests、181 DB checks、JS回歸、lint及build通過。此輪未更動DB、資料及Production。

限制：密集非樹狀關係仍可能有線與線交叉；交叉點不是實體節點。大量節點全圖fit會縮小文字，可縮放／拖曳近看。手動拖曳後可自行形成重疊，下次新增節點會自動重新排列。
