# 路徑圖手動擴張

原路徑節點誤被標記為已完成鄰居載入，點擊不會發出請求。本次將路徑種子與已載入頁面狀態分開。

- 公司A、公司B、共用人物及新增節點均可點擊，透過既有公開Graph API逐批載入12條關係；有下一頁時可再次點擊。
- 保留最初最短路徑及兩家公司標示；延伸節點正常顯示，不被原路徑聚焦效果淡化。
- 每次僅查一個節點，單圖最多60節點；查路徑的1–3段限制仍保留，手動展開不受該路徑長度限制。
- 不更動DB、身份配對或Production；只有已發布可公開的關係才能展開。即時觀察但未入庫的節點可能無鄰居可查。

定向JS回歸驗證橋接人物、新增公司再次展開、下一頁、去重、原始路徑與端點層級保留，以及60節點限制。
