The 462 Companies are a curated, verified Development set. They do not imply that all Taiwanese companies or their legal, labor and procurement histories are ingested. A live registry search may find additional companies while exposing their observations separately from published canonical relationships.

The mixed Company path regression originated in the live-investigation overview: its published-Entity action omitted `public_identifier`. When the user chose a live Company B, the browser asked the bounded path API for live comparison without Company A's uniform number; the API correctly rejected that incomplete request. The fix preserves the exact identifier in the selection and adds a regression assertion. It does not loosen API validation or create relationships.
