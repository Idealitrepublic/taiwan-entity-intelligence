# Local data

Large source datasets are kept locally and ignored by Git.

Expected development files:

- `directors.csv` — company director / supervisor source data
- `person_index.json` — local person index if generated
- `entity.db` — local SQLite entity database
- `tenders_gpa.json` — local government procurement source data

Keep the actual datasets out of the public repository unless licensing, privacy, and redistribution rights have been verified.

The code should treat source records as evidence and preserve source/date information whenever possible.
